# Copilot Instructions

## Project context
- This workspace is a small Python project focused on simple scripts and experiments.
- Keep changes minimal, clear, and easy to read.
- Prefer straightforward Python patterns over unnecessary abstraction.

## Coding guidelines
- Write clean, idiomatic Python.
- Use descriptive variable names and small, focused functions when helpful.
- Preserve the existing project structure unless a change clearly requires a new file or module.
- Keep comments brief and only add them when they explain non-obvious behavior.
- Avoid adding dependencies unless they are clearly necessary.

## Validation
- Run the relevant script or test command after making changes when practical.
- If the project is a single-file script, validate by executing the file with Python.
- Report any limitations or assumptions clearly when validation is not possible.

## Expectations for AI assistance
- Make the smallest safe change that solves the task.
- Do not broaden scope beyond the request.
- Preserve user intent and existing behavior unless the task explicitly requires a change.
- If a task is ambiguous, ask a clarifying question before making major edits.
